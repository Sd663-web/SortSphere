## 🚀 About

**SortSphere** is an interactive web application that helps users understand how different sorting algorithms work through real-time visualizations.

Whether you're a beginner learning Data Structures & Algorithms or someone preparing for coding interviews, SortSphere provides an intuitive way to see each sorting algorithm in action.

---

## ✨ Features

- 🎯 Interactive sorting visualization
- 📊 Random array generation
- ⚡ Adjustable sorting speed
- 📈 Adjustable array size
- 🎨 Clean and responsive UI
- ▶️ Start, Stop and Reset controls
- 📚 Educational visualization for DSA learners

---

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/Sd663-web/SortSphere.git
```

### Open the project

Simply open `index.html` in your browser.

No installation or dependencies required.

---

## 🎮 How to Use

1. Generate a random array.
2. Select a sorting algorithm.
3. Adjust the array size and animation speed.
4. Click **Start**.
5. Watch the sorting process step-by-step.
